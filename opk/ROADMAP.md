# OPK 업무 도구 — 디벨롭 방향

## 지금 들어가 있는 것

- 계약서: A4 편집, 조항·표·쪽 편집, 한/영/중 버전, AI 번역, **사진으로 새 계약서 만들기**, PDF·PNG·JPG·DOCX·전체 ZIP 다운로드
- 메일 서명: 사람별 서명, 양식 5종, 브랜드 로고 7종, 서식 복사·HTML 복사, 회사 공통 정보 일괄 적용
- 이 서버에 배포하면 로고 PNG 가 공개 주소(`/logos/…png`)로 열려서 **메일 서명 로고가 받는 쪽에서도 바로 보임**
- 비밀번호 로그인(관리자/직원) 또는 Cloudflare Access, 라이트·다크, 메뉴 접기

## 다음 단계 (우선순위 순)

1. **업체 주소록** — 시공사·거래처 정보(회사명, 대표자, 연락처, 주소, 계좌)를 한 번 저장해 두고 계약서 당사자 칸에 골라 넣기.
2. **계약 상태 관리** — 작성 중 / 보냄 / 서명 완료 / 보관 상태와 계약일·공사기간으로 목록 거르기.
3. **금액 자동 계산** — 총액을 넣으면 한글 금액(일금 ○○원정)과 지급 비율별 금액을 자동으로 채우기.
4. **변경 기록** — 저장할 때마다 이전 버전을 남기고(`updated_by` 포함) 되돌리기.
5. **PDF 원본으로 만들기** — 사진뿐 아니라 PDF 계약서도 읽어서 새 계약서로.
6. **서명·도장** — 대표자 도장 이미지와 손서명 패드로 서명란 채우기.
7. **업체용 보기 링크** — 로그인 없이 특정 계약서만 읽기 전용으로 보내는 기한 있는 링크.
8. **메일 서명 개인 링크** — 직원마다 자기 서명만 바로 열리는 링크.
9. **백업 내보내기** — 전체 데이터를 JSON 으로 내려받기 / 되살리기.

## 운영 원칙

- 홈페이지(opk-korea-main)와 Worker·DB·저장소를 섞지 않는다.
- 실제 계약 데이터(`seed.sql`)는 저장소에 올리지 않는다. 저장소에는 ○○ 예시만.
- 디자인 규칙은 OPK 디자인 시스템을 따른다(자간 넓히지 않기, 뉴트럴 그레이, 그린 #6eb92b 하나).
